## 2. 收费标准（建议）

内测期**免费**，跑通后转 **freemium + 按席/按量**：

| 档位 | 价格 | 内容 |
|---|---|---|
| Free | $0 | 1 个工作区、≤3 成员、每月 ≤100 封邮件摄取、≤1000 任务 |
| Pro | $10–20/席/月 | 无限任务、邮件/Excel 无限、自定义模板、照片 |
| Business | $29–49/席/月 | 团队、权限、审计、优先支持 |

定价锚点：Fieldwire / Jobber 的 $29–49/席/月；我们定位「比 Procore 轻、比 Excel 自动」，可往下打。多人协同 → 靠「一人用拉全队」的病毒传播，北极星指标是**团队激活率**。

## 3. AI 成本

- **规则优先（$0）**：关键词 + 线程归属已覆盖大多数场景，AI 是第二层。
- **何时加 AI**：规则抽不出字段 / 判断不了「改到哪个状态」时，用最小够用模型做兜底。
- **量级**：解析一封邮件 ≈ 一分钱以内；早期量级可忽略，远低于服务器开销。
- **原则**：别每封都调大模型——规则命中就不调 AI。

## 4. 关键风险与对策

| 风险 | 对策 |
|---|---|
| 邮件摄取不准（护城河失效） | 阶段 0 用真实邮箱反复测；先规则后 AI |
| 多人协作复杂度 | 用 Supabase Auth + Realtime，不自建 |
| 模板/矩阵维护成本 | 预设好模板 + 编辑所见即所得 |
| 冷启动没人用 | 内测免费 + 盯一个种子行业（工程/地盘）打样 |
