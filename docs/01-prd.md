# 01 · 产品需求文档（PRD）

> 版本 v1 · 状态：开发前基线 · 对应原型 `task-tracker.html`

## 1. 背景与问题

工程师/项目负责人的杂事分散在**收件箱**和**一堆 Excel 表格**里，每个任务还有大量碎片化状态（如地盘发现问题 → 出报价 → 等承办商报价 → 开工 → 完工 → 交发票）。现状是「共享 Excel + 邮件 + 群聊」，三个痛点：

1. **不自动化**：任务要手动录入，格式要自己定。
2. **格式漂移**：共享 Excel 没有统一模板，每人各写一套。
3. **追踪难**：多人协作时，不知道任务「现在在谁手里、进展到哪一步」。

## 2. 目标用户

- **种子用户**：5–50 人的小团队 / 工程地盘主管 / 运营 / 项目负责人（他们活在邮件和表格里，觉得 Asana/Procore 太重）。
- 定价锚点对标：Fieldwire / Jobber（$29–49/席/月）往下打。

## 3. 核心概念（术语表）

| 术语 | 含义 |
|---|---|
| **模板（Template）** | 一套可复用配置 = 状态流水线 + 类型 + 处理者矩阵 + 关键词。预设 + 可自定义 |
| **状态流水线（Statuses）** | 一串有序状态名，任务沿它流转（如 发现问题→出报价→…→交发票） |
| **类型（Category）** | 任务的属性/种类（如 一般、水喉、电气），决定处理者归属 |
| **处理者矩阵（Handler Matrix）** | `类型 × 状态 → 处理者` 的总表；任务到某状态时自动指派对应处理者 |
| **接受关键词（Accept keywords）** | 命中新邮件 → 自动建立任务 |
| **回复关键词（Reply keywords）** | 命中回复邮件 → 自动更新任务状态 |
| **发布者（Publisher）** | 谁发起任务 |
| **处理者（Handler）** | 任务当前在谁手里（由 类型×状态 自动决定） |
| **重要性（Priority）** | 紧急 / 重要 / 普通 |
| **NEW 标记** | 任务新建或状态变动后出现，点开即消（未读变更提示） |

## 4. 功能清单

### P0（MVP 必须）

- [ ] **邮箱绑定/监测**：绑定一个收件箱，命中关键词的邮件自动进「待确认」或自动更新状态
- [ ] **接受关键词建任务**：新邮件命中 → 生成任务草稿 → 人工确认入板
- [ ] **回复关键词更新状态**：回复邮件命中 → 按线程归属更新对应任务状态
- [ ] **Excel 导入**：上传 .xlsx → 解析 → 预览 → 导入为任务
- [ ] **手动建任务**：标题必填，含发布者/类型/重要性/截止
- [ ] **模板**：预设模板 + 自定义（状态/类型/处理者矩阵/关键词可编辑）
- [ ] **看板 + 表格双视图**：看板按状态分列；表格可排序、筛选、行内改状态
- [ ] **筛选**：来源筛选 + 类型筛选 + 搜索
- [ ] **状态流转 + 处理者自动切换**：按处理者矩阵
- [ ] **协同记录**：谁在何时把状态从 A 改为 B

### P1（内测增强）

- [ ] **多人协作**：账号登录、工作区、成员、权限、实时同步
- [ ] **NEW 标记**：未读变更提示
- [ ] **中英双语**：界面语言跟随模板语言
- [ ] **回复关键词 → 目标状态可配置**（当前按预设）

### P2（后续 / 第二增长曲线）

- [ ] WhatsApp 接入
- [ ] 照片/证据追踪（时间戳/GPS 水印）
- [ ] AI 抽字段（规则不够用时兜底）

## 5. 关键用户故事

1. 作为地盘主管，承办商回复「报价已发」，系统自动把「等承办商回报价」推进到「开工」，处理者自动切给王师傅。
2. 作为项目负责人，把本周收到的 20 封待办邮件一键变成团队看板上的任务，不再手动录。
3. 作为运营，上传一份 Excel 杂事表，3 行任务自动进看板并带截止日期。

## 6. 验收标准

| 功能 | 验收标准 |
|---|---|
| 接受关键词 | 命中邮件出现「待确认」草稿，确认后落到对应状态 |
| 回复关键词 | 命中回复邮件（含线程归属）后，对应任务状态变更 + 处理者切换 + 写协同记录 |
| Excel 导入 | 上传 → 预览 ≥1 行 → 确认导入 → 任务落到首状态 |
| 状态流转 | 任一入口（看板推进/步进器/表格下拉/回复）改状态，处理者按矩阵切换 |
| 模板 | 预设可切换，自定义可增删改，改动持久化 |
| 双语 | 切英文模板，全部界面（含弹窗/抽屉/Toast）变英文 |

## 7. 范围外（本版不做）

- WhatsApp、照片追踪、移动端 App、离线、多语言之外的更多语言、发票/支付流程（工具本身，不做财务）。
